# v0.6.3 release, 2026-11-23

A patch release cut by hand from main at 85c6477. It carries
implementation changes since v0.6.2 (63edc63), so the nightly pin job
would skip it.

## Changes since v0.6.2

- #433 makes the plain output explain profiles and settings:
  - `config` and `doctor` show the selected profile's base chain, its
    directory or that it is built in, and the settings path.
  - `pinfold profile` and `profile list` list every profile. They are
    exempt from the daily maintenance pass.
  - `config --json` gains `profile_chain`.
  - Plain `doctor` names an outdated image chain once.
  - Help folds `config edit` and `profile new` into their commands and
    merges the Advanced and Developers groups.
  - Plain `disk list` pads its columns.
  - The Apple builder's prune target after a build is 16 GB, up from
    4 GB. One four-image chain measured 2.5 GB (#392) and the owner's
    backing storage read 3.3 GiB, close to the old target; no eviction
    was measured. The new target leaves room for several chains.
- #435 makes `clean` and `doctor` say that disks are kept:
  - The disks line counts the disks and names both ways to remove
    them, `clean --unused AGE` and `disk rm`.
  - A real `clean` that saw disks ends with a line saying they were
    kept, or how many it removed under `--unused`.
  - Under `--unused`, a gone checkout is listed without the claim
    that its state and disks are kept.

## Audit

No whole-tree cleanup pass was run for this patch release. The v0.6.0
audit (2026-11-22-v0.6.0-code-cleanup.md) stands for the rest of the
tree. The rule in CLAUDE.md asks for that pass before every release
with implementation changes; it was skipped, as for v0.6.1 and v0.6.2.
#433 had one Codex review that reported one blocker (the profile
listing ran the maintenance pass) and ten minor findings. One fix
round fixed the blocker and three of the minor ones; the follow-up
reported one more minor finding. The eight declined are listed on the
PR. #435 had the same reviewer: two blockers (a predicted and a
derived disk count that could be false) and five minor findings. One
fix round removed both counts; the follow-up was clean with one minor
finding. Three were declined.
