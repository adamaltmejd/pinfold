# v0.6.1 release, 2026-11-22

A patch release cut by hand from main at 71533a6. It carries
implementation changes since v0.6.0 (e48f575), so the nightly pin job
would skip it, and its pins were moved by hand with the same steps.

## Changes since v0.6.0

- #422: each host secret is read once per launch, by the process that
  starts the box. A `from` name that is empty or holds `=` or NUL is
  refused as `spec`.
- #423: plain `doctor` prints a `Logins` line in a configured project
  (#419).
- #424: the project client prints the detail of a `spec` or `login`
  startup refusal, not only its token (#421).
- #425: `op = "op://…"` reads a secret from 1Password wherever `from`
  is accepted (#418).

## Pins

`scripts/bump-pins.py` moved nothing. Rust stays 1.100.0; the Cargo
requirements, the Public Suffix List, the codex app server and the
image tools are current. The script reported bun 1.4.5 and anydoc
0.2.5 as not yet eligible, so bun stays 1.4.4 and anydoc 0.2.4. Firecracker 1.18.0 waits for the guest kernel release
`guest-kernel-6.18.57-firecracker-v1.18.0`.

`cargo update` moved eight locked crates, all semver-compatible: bytes
1.12.2, cc 1.11.3, errno 0.3.15, hashbrown 0.17.2, mio 1.2.5,
pin-project-lite 0.2.18, rustls-webpki 0.103.17 and zeroize 1.9.2.
rustls-webpki 0.103.17 adds accessors only; mio 1.2.5 changes
platforms pinfold does not build for.
