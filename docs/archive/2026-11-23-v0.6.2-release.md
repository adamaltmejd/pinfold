# v0.6.2 release, 2026-11-23

A patch release cut by hand from main at 2d5104f. It carries
implementation changes since v0.6.1 (d82dda9), so the nightly pin job
would skip it.

## Changes since v0.6.1

- #431 fixes five tickets:
  - #305: Linux preflight refuses a dynamically linked pinfold with
    the token `static`.
  - #311: the proxy answers `Expect: 100-continue` itself, never
    forwards `Expect`, and refuses any other expectation with 417,
    logged `expectation unsupported`.
  - #413: a `PINFOLD_ENV_` variable whose name is not UTF-8 refuses
    the launch.
  - #414: the Git remote helper ends its crossing when Git closes its
    input. Row 47 kills Git alone.
  - #428: the default image runs Claude through a launcher that
    records its three first-run screens as answered for the project.
- #430 consolidates two modules:
  - #326: Apple `box exec` runs through the framed in-guest session
    path. `apple/transport.rs` is deleted.
  - #412: the proxy dials upstream through nix socket addresses. The
    hand-built sockaddrs and six unsafe blocks are deleted.

## Audit

No whole-tree cleanup pass was run for this patch release. The v0.6.0
audit (2026-11-22-v0.6.0-code-cleanup.md) stands for the rest of the
tree. Each PR had its own Codex review, with two fix rounds each.

The first review of #430 called a lingering guest relay a leak, and
a fix made the relay exit with its command. The second review showed
that this kills a process the command leaves behind at its next
write. The fix was reverted. The spec now states that such a process
keeps its relay until it closes its output or terminal.
