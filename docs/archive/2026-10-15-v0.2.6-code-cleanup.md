AGENTS.md. Coverage includes CLI; box/ownership/plan/network/pipe; both
runtime adapters and shared runtime; proxy/TLS; clean/image/artifacts/
download/profile; config/dirs/trust/init/main/update/login/build and guest
init; Pi; the E2E harness and every test/fixture; profile assets; the durable
prototype; scripts, workflows and repository configuration. Separate trace
and documentation reviews covered every configuration key, CLI verb/flag
and all 37 guarantee rows. Archived documents remain dated evidence.

Main CI was green before the audit. No other suite was using the local
runtime. Direct dependencies match all nine crates in Architecture's Code
section. Clippy with dead_code enabled reported no warnings. No TODO or
FIXME was found; XXX matches belong to public-suffix domain data.

- Landed: remove the obsolete five-line E2E module/scheduling description,
  which claimed only two exclusive scenarios. Locks, fixtures, code and
  assertions are unchanged.
- Landed: remove the README's contributor-process link. The specification
  link remains.
- Landed: describe G19's cached executable repair as the pi case. Initial
  launch/version and allowlist checks still cover pi, claude and codex.
  The guarantee and the test are unchanged.
- Written ticket [#97](https://github.com/adamaltmejd/pinfold/issues/97):
  consolidate runtime inventory completion observation. A text-only sketch
  could remove 49 lines, but its polling delay changes near-deadline
  outcomes. Keep the current mechanism until a smaller design preserves
  prompt completion, unreaped group ownership, cancellation and cleanup.
  No performance benefit is claimed.
- Retained: the Pi read-only mount ordering comment. It explains a security
  footgun, an allowed comment under AGENTS.md, rather than an obsolete path.
- Retained: runtime PATH resolution. Native spawn changes unset-PATH and
  all-EACCES behavior. Re-admission requires preserving the host boundary.
- Rejected: rewriting tag loops, buffering proxy parsing, or passing more
  precomputed state without a demonstrated cost or removed mechanism.
  Re-admission requires measurements and a smaller safe implementation.
- Retained: positive controls, ownership rechecks, hardlink/symlink guards,
  native runtime flags, deadline branches and integrity verification.
  Each serves a present contract; no control-removal proposal is admitted.

One finding became a new written ticket. Existing #89 remains the stock
Podman image-lock investigation. Existing #94 tracks four failure-only
trust-refusal checks in three G12 assertion blocks. The successful allowed
controls and all checks remain. A stable reason needs a separate diagnostic
contract change; this pre-existing limitation is not a new regression.

are separate slow gates; G35 is the durable prototype; G37 is Linux-only.
G19's Shown by wording is corrected as above. Every parsed configuration
key and CLI verb/flag has a spec entry. Sparse argv/help forms are not
missing guarantee tests. The profile file's own ignored profile key has

guarantee or a reason to add a shape test.

launched. Repeated installation requirements remain useful prerequisites.

nested Apple namespaces, herdr's environment reader and disk caps.

registers and implements getAuthStatus with includeToken/authToken;
