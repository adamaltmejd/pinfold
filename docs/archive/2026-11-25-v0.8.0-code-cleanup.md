## Landed

- A bug found by the spec reader: Git sends a chunked body for a POST
  over `http.postBuffer` (1 MiB by default), which the proxy refuses as
  `ambiguous framing`, so a larger push through the github login route
  failed. The route's Git configuration sets `http.postBuffer` for
  `http://github.localhost/` only to 524288000; a request that outgrows
  that buffer is still chunked and refused.
- Core: `Header.prefix` is a plain `String` again, a leftover of the
  removed `basic` option; an unreachable github check and two one-caller
  helpers are gone; three stale comments name `from` and github.
- Config: folder comments say a folder may be a share; the `config edit`
  template's env example no longer puts a secret in `env`, and it shows
  a commented github route.
- Row 26: the GitHub query refusal sends `?per_page=2;Access%5Ftoken=x`
  and counts upstream requests from just before it.
- README and spec: rationale for the github route, a duplicated Pi
  sentence, "(gates)" and a history sentence cut; three README sentences
  rewritten for clarity.
