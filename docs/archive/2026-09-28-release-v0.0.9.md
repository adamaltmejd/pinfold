## Landed

- 85ca02a spec, Y-108 cd071ee: a box protects only its image's last tag
  (#68).
- Y-109 5ea8071, a73c6e2: one runtime listing per maintenance pass, not
  two per source (#69).
- 1dcecaf spec, Y-111 b842428: Apple's root exec waits until the runtime
  lists the box running. Cause of the box loss in
  2026-09-28-apple-box-loss.md: Apple's `startProcess` starts init
  before it records `.running`, and `container exec` refuses a box not
  yet `.running`.
- Y-110 3c653ae: guarantee 19's damaged-install scenario uses a private
  cache. Since Y-104 it deleted pi from the cache the concurrent pi tests
  mount.
- 72fe1f0 spec, Y-112 3ec74b1: the runtime is found on the host's `PATH`,
  never the spec's (#70).
- e84d802 spec, Y-113 08c08d8, from this pass: retention reads box use
  after pruning, from every listed box. Y-109 had taken it before
  `pinfold clean`'s purge (a box started meanwhile could lose its image's
  last tag) and dropped dead boxes from it, then guarded that with a wait
  on pruning. One duplicate loop and three twin assertions went with it.
