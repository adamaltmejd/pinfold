# pinfold 0.1.0

This release hardens box preflight, fixes shared Apple builder races,
and establishes the baseline for nightly harness and image-tool updates.

- Fix concurrent Apple builds with different `NO_COLOR` or
  `BUILDKIT_COLORS` settings replacing each other's builder (#77).
- Preserve active Apple builds during cleanup and report allocated
  builder storage.
- Make doctor read-only and diagnose failed Podman host requirements.
- Update pi to 0.99.1, Claude to 2.1.285, and Codex to 0.159.2.
  The release pin-update run also checked Bun, RTK, and Ponytail.
- Nightly changed pins produce patch releases after Linux x64/arm64,
  full Mac live-login tests, and all three release builds pass.

## Caller changes

- `box up` now refuses suffix allow entries on or above a pinned public
  suffix as `spec`, before creating a box. Existing broad entries such
  as `.com`, `.github.io`, and `.amazonaws.com` must be narrowed.
- Missing or unreadable mount hosts, including dangling symlinks, now
  produce a `refused` line with reason `spec` before claiming the box
  name, rather than failing during startup. Symlinks to directories stay
  accepted.
- `doctor` no longer performs automatic maintenance. A failed runtime
  lookup is reported while doctor returns exit 0 rather than propagating
  that lookup failure as exit 1.
