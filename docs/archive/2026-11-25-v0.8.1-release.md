# v0.8.1 release, 2026-11-25

A release cut by hand from main. It completes v0.8.0's pre-release
audit, which read only the modules changed since v0.7.0; this one reads
the rest of the tree. The audit is in 2026-11-25-v0.8.1-code-cleanup.md.

## Changes since v0.8.0

- The whole-tree cleanup pass: deletions and consolidations in the CLI,
  both runtimes, images, the crossing, ownership, the guest init, the pi
  layer and the e2e harness, with no intended change in behavior. The
  export's file calls use nix instead of raw `libc`.
- The spec lists `apparmor-profile` among the commands that skip the
  daily pass, as the code already did.
- Rows 8, 43 and 50 are edited, with Adam's approval, to drop three
  assertions that could not fail silently or duplicated another.

## Caller changes

None.
