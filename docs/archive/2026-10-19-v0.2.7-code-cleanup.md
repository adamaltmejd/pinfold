# v0.2.7 cleanup and spec pass

2026-10-19. Baseline `fecf381`, main after #103. Latest release: v0.2.6.
Nightly pins failed on October 17, 18 and 19 by design: #101, #102 and
#103 changed implementation after v0.2.6, so the updater refused to
release them automatically. This pass releases them manually.

## Scope and method

Read-only reviewers read the whole tree with ARCHITECTURE.md and AGENTS.md:
cli and main; box, ownership, plan, network and pipe; both runtime
adapters and the shared runtime; proxy and TLS; clean, image, artifacts,
download and profile; config, dirs, trust, init, update and login; pi;
the E2E harness; the spec and `profile/`; README and built CLI help. The
test sweep covered every file under `crates/e2e/tests/e2e`. Each reviewer
had the October 15 dispositions so rejected findings did not return.

Main CI was green. Direct dependencies match the nine in Architecture's
Code section. Clippy with dead_code enabled reported nothing. No TODO or
FIXME. The one revisit trigger, `core/login.rs` getAuthStatus, has not
fired: the Codex pin stays 0.163.0.

Trace tables: all 37 guarantee rows map. 34 is an ignored test, 35 and 36
are standalone gates. Every configuration key and CLI verb has a spec line
and a test. Unexercised layer combinations (profile-level `routes`,
`protect`, `cpus`; explicit `allow = []`; `config ROOT`; `profile new
--from-project PATH`) are coverage distinctions, not missing guarantees.
`PINFOLD_BOX_ENV_`, defined in `init.rs` and exercised by `pi.rs`, is
internal transport with no spec line, not a user seam.

## Rejected

Each with the condition that would re-admit it.

- ownership's removals through `clean::remove_paths`: it deletes a file
  where a dir is expected and vice versa. Re-admit with identical kinds.
- proxy `Upstream::Address(String)`: std would resolve a bracketed
  non-IP route host differently. Re-admit if plan.rs refuses that form.
- TLS empty-record and no-extension early returns: removing them changes
  refusal reasons. Re-admit with a spec decision on the reasons.
- box `start`'s two blocking workers merged, and `actual`'s reordering:
  progress and lifecycle ordering change. Re-admit with a measured cost.
- plan's second `validate_guests`: a duplicate guest would be refused
  after the codex helper runs. Re-admit if the spec allows that order.
- main's `update` early return folded into the lock arm: it moves the
  exclusive install lock path. Re-admit with a lock-path review.
- profile `load` through `builtin`: it adds an error remap and removes no
  line.
- e2e `TestDir` newtype to a function: churn at 33 call sites for -9.
- `profile/documents/package.json` dedupe: it changes the documents
  profile's image inputs. Re-admit with a profile change.
- G16 memory read from cgroup instead of `box stat`: a guest cgroup limit
  is unverified under Apple's VM. Re-admit with a per-runtime observer.
- G29 noninteractive control with one non-terminal stream: a stronger
  scenario, not a cut. Re-admit as a bug through the CLI.
- G24 `untagged_images` inlined: it moves lines and removes none.
- doctor's no-runtime image fields in cli.rs: row 27 names that case.
- README update-notice and profile-sentence shrinks: no line removed.
