# v0.5.2

Fix upstream request-upload deadlines for HTTP and TLS connections. A
blocked write can no longer outlive its deadline. Proxy policy and timeout
values stay unchanged.

Reject route names that collide ignoring ASCII case before creating a box.
Announce image builds on stderr and clarify bundled-profile update advice,
including user-profile overrides and when rebuilding is necessary.

Expand real end-to-end coverage of Git metadata and worktree discovery
refusals. Remove duplicate checks without removing guarantee coverage.
Update Claude Code to 2.1.318 and the TOML dependency to 1.2.0.

## Caller changes

- **Hard break:** box specifications with route names differing only in
  ASCII case now fail with `spec`. Rename the colliding routes.
- Image builds print a start notice on stderr. Successful image-reference
  stdout and structured caller output remain unchanged.
- Bundled-profile advice explains effective user-profile overrides and
  rebuild commands. It does not rebuild images automatically.

No CLI flags, JSON fields or exit-code definitions changed.
