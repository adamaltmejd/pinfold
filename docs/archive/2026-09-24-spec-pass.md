## Rationale moved here from ARCHITECTURE.md

- Transport on Apple `container`: carrying the proxy socket over `--ssh`
  is off-label use of that flag. The fallback if it breaks is a per-box
  internal network with the proxy on the gateway and a root init that
  deletes routes (needs NET_ADMIN, SETUID, SETGID). apple/container#2247
  (relay data loss under parallel live connections) did not reproduce; if
  it does, multiplex all streams over one connection.
- No layer cache for profile and project builds: the default profile runs
  `apt-get upgrade`, and a cached layer would serve stale packages.
- `defaultProjectTrust: "always"` in the seeded pi settings: without it
  pi's non-interactive modes silently skip project config.
- Linux CI setup: the workflow installs the pinned toolchain's musl target
  and `musl-tools` (ring's C sources need them), enables linger and a
  D-Bus user session for the runner user so podman's cgroup manager is
  systemd, and clears AppArmor's unprivileged-userns restriction, which
  the runner image enables and which denies rootless podman its user
  namespace.
- "A Rust caller will link `core` and see the same operations as one that
  spawns `pinfold box`": a design intent, not a contract; `core` has one
  in-process caller, the pi layer.
